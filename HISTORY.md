# Reconstructed prototype snapshots

This commit reconstructs prototype 1.0 from its existing directory. It is not an original development commit; commit dates are migration dates. Credentials were removed before committing. External data, generated results, CA certificates and legacy raster placeholders are intentionally excluded.

The shared JEV modules, where needed, are the currently available shared copy; earlier revisions cannot be reconstructed. Historical image paths require the external legacy assets. No inference is made about their earlier content.
